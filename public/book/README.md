# Book cover assets — The Complete NCMHCE Study Guide

Print/design assets for the CounselorReady™ Exam Prep Series title
*The Complete NCMHCE Study Guide* (GA Integrated Therapeutic Perspectives LLC).

## `ncmhce-study-guide-cover.svg`

Standalone **front cover**, vector, self-contained (Montserrat + Inter subsetted
and embedded as base64; both OFL-licensed, so redistribution is permitted).

- **Canvas:** 6.25″ × 9.25″ — 6″ × 9″ trim + 0.125″ bleed on all sides.
- **viewBox:** `0 0 450 666` (1 user unit = 1 pt).
- **Palette:** mint gradient ground; navy `#153039`; series green `#2c8c67`;
  accent green `#2f9a70`; **ming green `#0f7a5e`** (series bar, title rule, and the
  "1,400+ …" stat line).
- **Cover copy figures are repo-derived** (`tools/cases/blueprint.js`): 92 distinct
  diagnoses across 18 diagnostic families. "1,400+ clinical decision-making
  questions" reflects the worked-case bank (108 cases × ~13 scored items = 1,404).
  The book's own practice content — 3 full-length exams, 33 cases, 429 scored
  questions — is separate and unchanged.

Edit in any SVG tool, or regenerate from the design script kept with the print
wrap build. The full print-ready paperback **wrap** (back + spine + front, with QR
and barcode-safe zone) is produced as a flattened PDF for KDP upload; ask for the
current wrap PDF or its build script if you need to regenerate it.
